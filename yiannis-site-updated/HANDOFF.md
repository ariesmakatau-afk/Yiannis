## What changed in this round

1. **Address confirmed** — `business.address.confirmed` is now `true` in `lib/content.ts`.
2. **Sauces list finalized** — 11 sauces in `lib/content.ts` (`sauces` category), 50c each:
   Garlic, Mustard, Peri Peri, Nando's Peri-Peri, Aioli, Mayonnaise, Hot Chilli, Sweet Chilli,
   Tomato, BBQ, Tabasco.
3. **Full drinks menu added** — split into 5 new categories in `lib/content.ts`:
   `drinks-soft`, `drinks-powerade`, `drinks-water`, `drinks-juice-milk`, `drinks-cans`
   (plus the original `drinks` category, which just has Greek Coffee). All new items are
   priced `"Price on request"` — **search `lib/content.ts` for "Price on request" and replace
   with real prices** once the client provides them, then you can retire the note in
   `menuPlaceholders.drinks`. All 5 new categories are already wired into `/menu` (display)
   and `/order` (pickup builder) via `orderableCategoryIds` in `lib/content.ts` — no other
   code changes needed once prices are in.
4. **Logo integrated.** The client supplied a photo-style mockup (`Spartan warrior` emblem,
   text "YIANNIS / HELLANIC YIROS") with a marble-and-vignette background — not a usable
   web asset as-is. I isolated the artwork by masking on hue (navy ink vs. neutral grey/black
   backdrop) and produced clean transparent PNGs, saved to `public/images/`:
   - `logo-navy.png` / `logo-white.png` — full lockup (icon + wordmark), 1212×797
   - `icon-navy.png` / `icon-white.png` — icon only (no wordmark), 815×478
   - `logo-navy-icon-512.png` — a downscaled navy lockup, spare/unused
   - `app/icon.png` — square favicon generated from the icon mark on a navy circle

   **Flag for the client:** the logo's subtitle reads "HELLANIC YIROS" — almost certainly
   meant to be "Hellenic." Wasn't changed since it's their supplied artwork; check with them
   before it goes live everywhere. If they send a corrected or vector (SVG/AI/EPS) version of
   the logo, redo this asset pass from that instead of the current raster extraction — it'll
   look sharper at large sizes (e.g. the About page lockup) than the current raster masks do.

   Used in: `components/Header.tsx` (icon-white, compact), `components/Footer.tsx`
   (logo-white, full lockup), `app/about/page.tsx` (logo-navy, full lockup), `app/page.tsx`
   hero (icon-white as a low-opacity watermark), `app/icon.png` (favicon).

5. **Color palette matched to the logo** — sampled the logo's navy directly from the
   artwork and updated `tailwind.config.ts`: `cobalt.DEFAULT` is now `#0d3b6f` (was
   `#1747a6`). `cobalt.light` / `cobalt.dark` were adjusted to match.
6. **Greek meander (key pattern) theme extended.** There was already a `.meander-divider`
   utility in `app/globals.css` (white, used once in the footer). Added a
   `.meander-divider-navy` variant and placed small accent dividers under the page `<h1>` on
   About/Menu/Location/Contact, and above "Why Yianni's" on the homepage, to carry the motif
   (referenced from the client's Canva mood image of 3D Greek columns/marble) through more of
   the site without it feeling like a one-off footer decoration.

## Update — "HELLENIC" spelling corrected

The client's original logo artwork read "HELLANIC YIROS." Since no corrected source file was
supplied, I fixed it directly in the existing raster assets: the "A" in "HELLANIC" was
replaced with the "E" glyph copied from elsewhere in the same wordmark (same font, weight,
color, baseline — pixel-perfect match, no font-guessing involved), then centered in place.
Fixed files: `public/images/logo-navy.png`, `public/images/logo-white.png`, and the spare
`public/images/logo-navy-icon-512.png` (regenerated by downscaling the fixed navy lockup).
`icon-navy.png` / `icon-white.png` / `app/icon.png` never contained the wordmark text, so
they were untouched.

**If the client later sends a proper corrected or vector logo file, redo this asset pass from
that instead** — it'll be sharper at large sizes than this raster patch, especially for the
About page's full-size lockup.
