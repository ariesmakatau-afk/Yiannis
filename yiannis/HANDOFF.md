## Update — lighter theme + Greek-inspired type system

Reworked the visual language per client direction: "blue and white, but lighter, chill vibes"
plus real Greek-style calligraphy instead of the plain sans-serif.

- **Palette softened** (`tailwind.config.ts`): the old strong navy (#0d3b6f/#082746) is now a
  "harbor blue" (`cobalt` = #2f5578 / light #6d93b4 / dark #1c3850) — still clearly "the blue,"
  much less heavy. Contrast-checked against white text (7.8:1 DEFAULT, 12:1 dark — both pass
  WCAG AAA). Added `mist` (#eef3f5, pale blue-grey) for alternating section backgrounds instead
  of flat white/cobalt-tint, and `sand` (#faf8f4, warm off-white) as the new body background —
  the whole site no longer sits on stark white.
- **Typography** (`app/layout.tsx`): swapped Space Grotesk for **Cinzel** (a serif carved from
  actual Roman/Greek inscriptional lettering) as the display/heading font, and added
  **Cormorant Garamond italic** as a script accent font (`font-script`) for small taglines —
  e.g. "Est. on Hindley Street" over the hero, "Yamas!" over the final CTA. Body copy stays on
  Inter for readability.
- **New decorative motif**: `public/images/marble-scene.svg` — an original, hand-built SVG
  (soft blue-grey gradient, one large "orb," abstracted column line-art, a meander trim strip)
  used via the new `.scene-bg` utility class behind the hero and the two navy call-to-action
  sections on the homepage. This is intentionally *not* a copy of any reference/mood-board
  image — the client's references included another studio's Canva stock asset and two other
  restaurants' branding (PHEAS, NOMA), which aren't ours to reuse on a paying client's site, so
  the mood was rebuilt from scratch as original artwork instead.
- Logo files were **not** recolored — they stay the bold "signature" navy from the brand mark,
  which now reads as an intentional deeper accent against the lighter site chrome.

Because the whole codebase already used semantic classes (`font-display`, `bg-cobalt`,
`text-cobalt`) rather than one-off hex values, this change cascades through every page
automatically — About/Location/Contact/Order all pick up the new palette and type without
being touched individually. Homepage got extra hand-styling (script taglines, the marble scene
on hero + two CTA blocks) since it's the highest-visibility page.

**Next up, by design:** the actual `/menu` page layout and the `/order` builder UI haven't been
redesigned yet — they're functionally intact but visually still plain. That's the deliberately
separate next step (menu content/pricing was already finished in the previous pass; now it's a
pure visual pass on the same new design system).

## Update — new medallion logo, marble theme, Fraunces + Sora type

Client supplied two new images this round: a **circular marble medallion logo** (Spartan
relief, Greek-key border, "YIANNIS / HELLENIC YIROS" — spelling now correct in the artwork
itself) and an **architectural marble still-life** (plaster wall, fluted columns, marble
spheres, a carved rosette) to drive the site's visual theme.

### Logo
- Background removed: the medallion was isolated from its marble-slab backdrop with a
  feathered circular mask, cropped tight. Saved as `public/images/medallion.png` (1024px
  master), `medallion-512.png` (in-page use) and `medallion-160.png` (small/spare).
- **The old header-logo distortion is fixed.** The previous header squeezed the 815×478
  *wide* `icon-white.png` into an `h-10 w-10` *square* box, which is what made it look
  mushed. The new mark is square, sits in a square box, and the header is now 72px tall with
  proper spacing and a `truncate`-safe two-line wordmark.
- The medallion now appears in the header, footer, About page, `/menu` (as a faint
  watermark), the hero (as the centrepiece) and `app/icon.png` (favicon, on brand blue).
- **Superseded assets deleted**: `icon-navy.png`, `icon-white.png`, `logo-navy.png`,
  `logo-white.png`, `logo-navy-icon-512.png`, and the previous hand-built `marble-scene.svg`.
  All references were updated — nothing points at them anymore.

### Typography — Fraunces + Sora
`app/layout.tsx` now loads **Fraunces** (display/headings + italic for taglines) and **Sora**
(body, nav, UI). Both are variable fonts, so no fixed `weight` arrays are passed — only
`axes: ["SOFT", "WONK"]` on Fraunces for its characteristic soft wonk. Cinzel, Cormorant
Garamond and Inter are gone. `h1–h4` switched from `tracking-wide` to `tracking-tight`, since
Fraunces has enough character of its own and doesn't want letterspacing.

### Theme — the still-life, used as a design system (not pasted in)
The reference image was **decomposed into reusable parts** rather than dropped in as a
background:

| Asset | Source | Used as |
|---|---|---|
| `texture-marble.jpg` | clean top-left wall texture | tiling ground for `.marble-surface` / `.marble-wash` |
| `scene-feature.png` | full columns + rosette composition, edge-feathered | `.scene-bg` atmosphere behind hero and the two blue CTA bands |
| `column-left.png`, `column-right.png` | the two fluted/doric columns, feathered | flank and visually "support" the shopfront image on the homepage About block |

New utility classes in `app/globals.css`:
- `.marble-surface` / `.marble-wash` — textured section grounds (replaces flat `bg-mist`)
- `.scene-bg` — the still-life as atmosphere
- `.plinth` — a marble ledge-and-shadow that objects stand on; used under each
  "What's Cooking" tile and the shopfront image, echoing the reference's marble shelf
- `.btn-orb` / `.btn-orb-blue` — **the marble spheres reinterpreted as buttons**: fully round
  pills with a radial gradient lit from the top-left (matching the reference's light
  direction) plus inner and drop shadows. `btn-orb` is the pale marble one, `btn-orb-blue`
  the brand-blue primary. These replaced `btn-primary` / `btn-secondary` /
  `btn-outline-dark` sitewide.
- `.carved-panel` — bas-relief card: light top edge, soft inset + drop shadow, as if recessed
  into stone. Used for menu categories, review cards, the map placeholder and OrderFlow panels.
- `.menu-panel` / `.menu-panel-link` — **the themed dropdown**: the mobile menu is now a
  translucent marble panel with a Greek-key trim strip along its top edge, large Fraunces
  labels with arrow affordances, and an orb CTA at the bottom. The same `.menu-panel`
  treatment is reused for the `/menu` sticky category bar and the mobile bottom nav.

Header also flipped from solid blue to a translucent marble/sand bar, so the blue is now an
accent against the marble rather than the site's dominant colour — closer to the reference's
light, stone-forward feel. Desktop nav breakpoint moved `md` → `lg` to give the longer
Fraunces wordmark room before it collapses.
